# DB MCP v0.1.2

This release adds in-app update checks and installation for future releases.

## What's new

- DB MCP checks for updates when it starts and notifies you when a release is available.
- Settings → About shows the release notes and download progress.
- Choose **Download and restart** to install an update. DB MCP stops its local server during installation and restarts the app afterward.
- Update packages are signed and verified before installation.

## Updating from v0.1.1

Version 0.1.1 does not include the updater. Install v0.1.2 manually once; DB MCP can then install later releases from the app.
